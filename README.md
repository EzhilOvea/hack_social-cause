TicketSafe is a clickable, single-file prototype (ticketsafe-prototype.html, no install or server needed, just open it in a browser) of a phone-linked digital backup for lost paper tickets, built so that a lost ticket does not mean a lost day's wages. It walks through the full journey in three tabs: buy a ticket, which is saved against the buyer's mobile number; recover it by SMS, missed call or kiosk with no app needed, where a 4-digit OTP and a destination check confirm ownership before a duplicate code is issued and the old ticket is voided (three wrong tries lock the request); and an inspector check that shows Valid, Voided or Not found and flags reissued tickets. A demo ticket for 9876543210 (Madurai to Chennai Egmore) is preloaded, so you can open the Recover tab, send "LOST", enter the on-screen demo OTP, reply "Chennai Egmore" and see the result. All data is simulated and held in memory, with no real SMS, USSD or voice gateway, no scannable QR, and no true offline sync, so treat it as a design demo rather than production software.
